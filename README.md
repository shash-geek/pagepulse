# Page Pulse

A web application that audits any website URL and generates an SEO/technical report.

## Features

- HTTP Status
- Response Time
- Page Title
- Meta Description
- H1 Count
- Total Images
- Images Missing Alt
- Approximate Word Count
- Proper Error Handling

## Tech Stack

- React
- Tailwind CSS
- Express
- Node.js
- Axios
- Cheerio

## Installation

### Backend

cd server
npm install
npm start

### Frontend

cd client
npm install
npm run dev
